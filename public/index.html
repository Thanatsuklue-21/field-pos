สัดส่วนต้นทุนต่อแก้ว

ต้นทุนคงที่ต่อแก้ว = ต้นทุนคงที่ต่อเดือน ÷ เป้ายอดขายต่อเดือน · ต้นทุนผันแปรอื่นและต้นทุนแฝงแสดงแยก ไม่รวมใน Actual COGS

หมวดเมนูเมนูสูตรวัตถุดิบบรรจุภัณฑ์น้ำแข็งActual COGSรายละเอียด
เลือก “แจกแจง” ที่เมนูเพื่อดูปริมาณ ราคาต่อหน่วย และแหล่งข้อมูล
ราคาขายไม่เปลี่ยนอัตโนมัติ ระบบแสดงราคาที่แนะนำจากทั้งเป้า COGS และเป้ากำไรสุทธิ เพื่อให้เจ้าของร้านพิจารณา
หมวดเมนูราคาขายปัจจุบันต้นทุนเต็มราคาตามเป้า COGSราคาตามเป้ากำไรราคาแนะนำ
กำไรขั้นต้นหัก Actual COGS · กำไรส่วนเกินหักต้นทุนผันแปร · กำไรสุทธิโดยประมาณหักต้นทุนคงที่จัดสรรและต้นทุนแฝงเพิ่มแล้ว
เมนู/สูตรราคาขายActual COGSกำไรขั้นต้นกำไรขั้นต้น %กำไรส่วนเกินกำไรสุทธิประมาณกำไรสุทธิ %

🌐 เตรียมฐานข้อมูลออนไลน์

ขณะนี้ POS ยังบันทึกในเครื่องนี้ API PostgreSQL สำหรับบัญชีและนำเข้าข้อมูลอยู่ในแพ็กเกจเซิร์ฟเวอร์ การรับเงิน/ตัดสต๊อกออนไลน์ยังไม่เปิดจนกว่าจะทดสอบธุรกรรมฝั่งเซิร์ฟเวอร์

โหมดข้อมูลที่ใช้อยู่ออฟไลน์ · IndexedDB + LocalStorage
